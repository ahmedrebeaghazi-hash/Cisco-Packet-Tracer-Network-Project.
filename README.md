# Kleines Netzwerkprojekt – Cisco Packet Tracer

## Projektbeschreibung

Dieses Projekt umfasst den Aufbau und die Simulation eines kleinen Netzwerks mit Cisco Packet Tracer.

Ziel des Projekts ist es, grundlegende Kenntnisse der Netzwerktechnik praktisch anzuwenden und ein besseres Verständnis für die Kommunikation zwischen verschiedenen Netzwerkgeräten zu entwickeln.

## Verwendete Software
- Cisco Packet Tracer

## Projektziele
- Aufbau einer einfachen Netzwerkstruktur
- Verbindung verschiedener Netzwerkgeräte
- Verständnis grundlegender Netzwerkkommunikation
- Praktische Anwendung theoretischer Netzwerkkenntnisse

## Was ich gelernt habe

Durch dieses Projekt konnte ich meine Grundlagen in der Netzwerktechnik vertiefen und erste praktische Erfahrungen mit der Netzwerksimulation sammeln.
